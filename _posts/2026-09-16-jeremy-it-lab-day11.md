## day11 - 라우팅 기초

1. 라우팅의 정의와 학습 방식
    - 라우팅의 정의 : 라우터가 IP 패킷을 수신했을 때 목적지 네트워크까지 최적의 경로를 결정하여 올바르게 전달(포워딩)하는 전반적인 프로세스이다. 

    - 테이블 비교
        - 스위치는 L2 목적지 물리 주소를 기록하는 MAC 주소 테이블을 유지한다.
        - 라우터는 알려진 목적지 L3 네트워크 목록과 전달 지침을 기록하는 라우팅 테이블을 유지한다.
    
    - 경로 학습 방식 2가지
        - 동적 라우팅(Dynamic Routing) : OSPF 등 동적 라우팅 프로토콜을 통해 라우터까리 라우팅 정보를 자동으로 교환하여 테이블을 구축
        - 정적 라우팅(Static Routing) : 네트워크 관리자가 수동을 직접 경로를 입력
        - 해당 포스트에서는 두 범주에 속하지 않고, 인터페이스 활성화 시 시스템에 의해 자동으로 등록되는 특수 경로(Connected & Local)를 중점적으로 다룬다.

2. 라우팅 테이블 구조 및 자동 생성 경로
    - 라우터 인터페이스에 IP 주소를 설정하고 `no shutdown`으로 활성화 하면, 라우팅 테이블(`show ip route`)에 포트당 2개의 경로가 자동으로 등록된다. 
    ```
    C    192.168.1.0/24 is directly connected, GigabitEthernet0/2
    L    192.168.1.1/32 is directly connected, GigabitEthernet0/2
    ```

    1. Connected 경로(코드 C)
        - 대상 : 인터페이스가 속한 서브넷/네트워크 전체(`/24`등 설정된 서브넷 마스크 적용)
        - 예를 들면 `g0/2` 포트 IP `192.0.168.1.1/24`를 부여하면, 해당 인터페이스는 같은 네트워크에 있는 `192.168.1.0 ~ 192.168.1.255` 범위 전체를 목적지로 인식한다.
        - 해당 상태는 동일한 스위치/케이블로 붙어있는 상태로 다른 라우터에 넘길 필요 없이 `g0/2` 포트로 패킷을 바로 밀어내어 대상 기기에 직접 전달한다. 
    
    2. Local 경로(코드 L)
        - 대상 : 라우터 인터페이스 자체에 실제 할당된 고유 IP 주소 단 하나, 라우터 포트 본인에게 할당된 고유 IP 주소
        - 프리픽스 마스크 : 특정 단일 호스트만을 지칭하기 위해 항상 `/32` 넷 마스크를 사용한다(`255.255.255.255`).
        - 자체 수신 : 패킷을 외부 다른 장비로 포워딩 할 필요 없이 L2/L3 헤더를 벗겨내고 라우터 내부 OS(Ping응답, SSH 접속, 라우팅 정보 교환)로 전달하여 라우터가 직접 응답한다.

3. 경로 매칭(Route Matching)과 최장 프리픽스 매칭(LPM) 규칙
    - 라우터가 목적지 IP를 가진 패킷을 받았을 때 라우팅 테이블에서 최적 경로를 결정하는 2대 핵심 규칙이다. 

    1. 경로 매칭
        - 패킷의 목적지 IP가 라우팅 테이블에 정의된 네트워크 범위 내에 포함되어야 해당 경로와 매치 된 것으로 본다. 
    
    2. 최장 프리픽스 매칭(Longest Prefix Match / Most Specific Match)
        - 하나의 패킷 목적지 IP가 라우팅 테이블의 여러 경로와 동시에 매치될 경우, 네트워크 비트수가 가장 긴 (프리픽스 길이가 가장 큰/가장 구체적인)경로를 최종 선택한다.

4. 라우터 vs 스위치 결정적 동작 차이
    - 스위치(Switch)
        - 프레임의 목적지 MAC 주소를 모를 때 인입 포트를 제외한 모든 포트로 플러딩(Floodig)한다.
        - 테이블에서 항상 완전 일치하는 주소만 찾느다. 
    
    - 라우터(Router)
        - 패킷의 목적지 IP와 매치되는 경로가 라우팅 테이블에 전혀 없으면, 패킷을 절대 플러딩하지 않고 즉시 폐기한다.
        - 테이블에서 가장 구체적인 경로를 탐색한다.

5. `show ip route` 출력 화면의 기타 안내 문구
    - 라우팅 테이블 상단에 출력 되는 `192.168.1.0/24 is variably subnetted, 2 subnets, 2 masks` 같은 문구는 실제 라우팅 경로가 아니다.
        - `192.168.1.0`(부모 네트워크) : 아래에 나올 하위 경로들이 속해 있는 기준 네트워크 범위
        - `is variably subnetted`(가변 서브넷) : 해당 범위 안에 서브넷 마스크 길이가(/24, /32)가 서로 다른 다양한 경로가 섞여 있다.
        - `2 subnets`(하위 경로 개수) : 이 그룹 아래에 실제 라우팅 경로가 2개 존재한다.
        - `2 masks`(마스크 종류 개수) : 사용된 서브넷 마스크의 종류가 2가지(예 /24, /32)라는 뜻이다.
    
    - 해당 클래스 플 네트워크 범위 내에 서로 다른 서브넷 마스크를 가진 세부 세브넷 경로들이 존재함을 요약해 주는 시스템 헤더 헤드라인일 뿐, 경로 부석 시에 이를 무시하고 아래의 실제 경로(`C, L`)들만 확인하면 된다.


### 주요 어휘

| 영문 표현 | 뜻 / 문맥 | 쓰임새 |
| :--- | :--- | :--- |
| Routing Table | 라우팅 테이블 | 패킷 포워딩 경로 및 목적지 네트워크 정보가 등록된 라우터의 핵심 데이터베이스 |
| Connected Route (C) | 직접 연결 경로 | 라우터 인터페이스에 연결된 서브넷 전체를 나타내며 인터페이스 활성화 시 자동 등록 |
| Local Route (L) | 로컬 주소 경로 | 라우터 인터페이스 자체의 IP 주소를 가리키는 /32 경로로 패킷의 자체 수신에 사용 |
| Longest Prefix Match (LPM) | 최장 프리픽스 매칭 | 여러 경로가 매치될 때 서브넷 마스크 비트 수(프리픽스 길이)가 가장 긴 경로를 우선 선택 |
| Most Specific Route | 가장 구체적인 경로 | IP 대역 범위가 가장 좁고 상세하여 라우터가 최우선으로 선택하는 경로 |
| Next Hop | 넥스트 홉 | 목적지 네트워크로 가기 위해 패킷을 넘겨주어야 할 경로 상의 바로 다음 라우터 IP |
| Drop | 폐기 (드롭) | 라우팅 테이블에 일치하는 목적지 경로가 없을 때 라우터가 패킷을 버리는 동작 |
| WAN (Wide Area Network) | 광역 통신망 | 서로 다른 도시나 국가 등 지리적으로 멀리 떨어진 LAN들을 라우터로 연결한 대규모 망 |
| Hop Count | 홉 수 | 패킷이 최종 목적지에 도달하기까지 거쳐 가는 라우터의 개수 |
| Variably Subnetted | 가변 서브넷 구성 | 라우팅 테이블 내에 동일 주요 네트워크에 속하면서 마스크 길이가 다른 경로들이 공존함 |
